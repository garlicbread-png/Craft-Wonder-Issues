# 🛠️ Craft & Wonder - Official Issue Tracker

Welcome to the official bug tracker for **Craft & Wonder**! This repository is dedicated to tracking, organizing, and fixing bugs, crashes, and performance issues within the modpack.

Before submitting a report, please read the guidelines below to help us fix your problem as quickly as possible.

---

## 🔍 Before You Report

1. **Check for Duplicates:** Use the search bar at the top of the [Issues](https://github.com/garlicbread-png/Craft-Wonder-Issues/issues) page to see if someone has already reported your problem.
2. **Update the Pack:** Ensure you are playing on the latest version of the modpack. Your issue might already be fixed!
3. **Is it a Modpack Bug?** I can only handle bugs caused by mod interactions, custom configurations, quests, or script errors. 
   * *If an individual mod is broken on its own in a vanilla profile, please report it directly to that specific mod author's tracker instead.*

---

## 📝 How to Submit a Good Bug Report

To help us diagnose and fix your issue, please click the **"New Issue"** button and fill out the provided template. Make sure to include:

* **Modpack Version:** (e.g., v1.2.0)
* **Environment:** Are you playing on a Singleplayer world or a Multiplayer Server?
* **Clear Steps to Reproduce:** Exactly what were you doing right before the problem occurred?

### ⚠️ Crash Logs are Mandatory
If your game crashed or froze, I **cannot** help without a log file. 
1. Locate your modpack directory.
2. Open the `crash-reports` folder or the `logs` folder.
3. Open the latest file, copy all text, and paste it into [mclo.gs](https://mclo.gs) or [Pastebin](https://pastebin.com).
4. Paste the resulting link into your GitHub issue.

> 🛑 **DO NOT paste raw logs directly into the GitHub text window.** It makes the issue unreadable.
---

Thank you for helping improve the modpack!
